## 🚀 Projetos em destaque

### 🟣 [agent-sync](https://github.com/matheusbbdutra/agent-sync)
Plataforma de orquestração de hooks/MCPs/skills para 6 CLIs de IA (Claude Code, Codex, Cursor, Antigravity, OpenCode v2, Cline). Memória persistente, governança de contexto e telemetria — escrita em **Go** com plugins **TypeScript**.

### 🟢 [wisp-db](https://github.com/matheusbbdutra/wisp-db)
SQL client desktop nativo e leve, construído com **Go + Wails**. Multi-tab, streaming de resultados, SSH tunneling e schema explorer para PostgreSQL, MySQL e SQLite.

### 🟠 [portfolio](https://github.com/matheusbbdutra/portfolio)
Portfólio pessoal — bento grid responsivo, hero adaptável para mobile, feito com **Vite + React + TypeScript**.
